# 일괄 업데이트 예시

- 값만 변경하는 작업과 표·서식·차트 등 구조 변경을 구분한다. 값 변경 도구에는 확인한 A1 범위와 값만 보낸다.
- 구조 업데이트의 `GridRange`가 필요할 때는 메타데이터의 숫자 `sheetId`를 쓰고, 시작 인덱스는 0부터, 끝 인덱스는 제외되는 값으로 계산한다.
- 예를 들어 확인된 탭의 `A2:B4`는 `startRowIndex: 1`, `endRowIndex: 4`, `startColumnIndex: 0`, `endColumnIndex: 2`로 표현한다.
- 일부 셀 속성만 바꾸는 요청은 허용되는 필드 마스크에서 필요한 필드만 지정한다. 연결 도구의 실제 스키마에서 요청명을 확인한다.
- Excel에서 가져온 표의 선택형 열을 Sheets 기본 표의 `DROPDOWN`으로 바꾸기 전에 표 ID, 열 인덱스, 유효 옵션과 기존 값을 확인한다. 변경 후 표 메타데이터와 대표 셀을 다시 읽는다.
