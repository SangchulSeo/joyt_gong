# 실시간 조회와 검색

- 메타데이터의 실제 탭 이름과 표 시작 위치를 사용한다. 기본 탭 이름이나 헤더 행을 추측하지 않는다.
- A1 범위는 필요한 열과 행을 좁혀 지정한다. 탭에 공백이 있으면 작은따옴표로 감싼다. 예를 들어 `'질문·답변 관리'!A4:K20`을 쓴다.
- 범위나 탭 오류가 나면 메타데이터를 한 번 다시 읽어 이름과 경계를 바로잡는다. 통합 문서 전체나 너무 넓은 범위를 반복 조회하지 않는다.
- 행 검색은 실제 헤더와 제한된 행 범위에서 실행한다. 결과가 없으면 필드명, 검색어, 헤더 행과 범위를 순서대로 확인한다.
- 계산된 값과 수식 정의가 모두 필요하면 각각에 맞는 읽기 옵션을 사용한다.
