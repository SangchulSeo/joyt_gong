# 편집 흐름

1. 대상 문서와 수정 권한을 확인한다. 원본과 결과가 별개라면 각각의 ID를 비교한다.
2. 메타데이터로 탭 이름·ID, 크기와 범위를 확인하고 실제 헤더 및 예제 행을 지정 범위에서 읽는다.
3. 변경 범위와 유지할 수식, 입력 규칙, 서식 및 보호 범위를 파악한다. 기존 수식이나 옵션 셀이 포함된 행은 쓰기 직전에 다시 읽는다.
4. 값 변경과 구조·서식 변경을 나눈다. 범위가 바뀌는 구조 변경 이후에는 다시 조회한 좌표를 쓴다.
5. 변경한 범위와 경계 행을 읽어 확인한다. 원래대로 남아야 할 값과 수식, 검증 목록, 머리글을 함께 확인한다.
