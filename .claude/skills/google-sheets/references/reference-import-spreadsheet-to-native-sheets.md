# Excel을 Google Sheets 형식으로 가져오기

1. 준비된 통합 문서를 열어 탭 이름, 데이터, 헤더와 대표 수식을 확인한다.
2. Drive가 Google Sheets 형식으로 변환해 가져오기를 지원하는지 확인한다. 저장 위치는 사용자가 지정한 폴더를 우선한다.
3. 결과의 문서 ID와 Google Sheets URL 또는 MIME 유형을 확인한다. 변환 전 Excel 파일과 결과를 구분한다.
4. 가져온 탭에서 누락된 행·열, 수식 오류, 드롭다운, 날짜와 숫자 형식이 있는지 확인한다.
5. 표와 드롭다운을 원본 Sheets 표로 올려야 하면 일괄 업데이트 지침을 따른다. 변환 후 최종 URL은 실제 만들어진 파일에서 가져온다.
